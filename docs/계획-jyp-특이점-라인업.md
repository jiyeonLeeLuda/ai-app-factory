# JYP Blue Garage 대응 — 특이점 라인업 (계획 v2 후보)

작성: 2026-09-15. `계획.md`의 라인업(W1~W7)에 대한 교체/혼합 후보.
계기: JYP 자회사 Blue Garage "AI Artist / Full Stack" 공고 발견 + "낡은 기술을 수면 위로" 전략 채택.

## 1. 공고 요약 (recruit-apply.jype.com/ko/o/157767)

- Blue Garage: JYP 자회사(구 JYP360), IP × AI 플랫폼. AI사업실 = Creative + Engineering.
- 직무: AI 아티스트와 팬이 상호작용하는 신규 모바일 서비스 풀스택. 경력 3년+, 정규직, 서울(강동).
- 주요 업무: React Native 크로스 플랫폼 앱, 실시간 채팅, AI 생성 음성/영상 스트리밍 통화,
  리얼타임 백엔드, AI 모델 연동과 추론 파이프라인, 품질/성능 모니터링.
- 자격: TypeScript, WebSocket/WebRTC, REST API와 DB 모델링, Python 또는 Node.
- 우대: LLM/TTS 연동, Docker/AWS, Sentry류 모니터링, 팬덤 도메인, 글로벌 서비스, 기획~운영 전 과정.

## 2. 적합도

- 충족: TypeScript, REST/DB, Python/Node, 경력 3년+, 글로벌(일본) 서비스와 다국어, 기획~운영 전 과정.
- 시간차 자산: WebRTC와 STT-TTS 대화 흐름은 2019~2020 실무(V-PAY 음성 주문, PT 플랫폼 WebRTC) —
  낡았지만 "LLM 이전에 몸으로 풀어본 기록"이라 부활시키면 특이점.
- 격차: React Native, LLM/TTS 최신 연동, 현대적 실시간 스트리밍 구현.
- 정체성 정합: 미술 전공 × 개발 × AI × 로봇 — Creative × Engineering 조직에 그대로 꽂힘.

## 3. 특이점 전략 (합의됨)

- 원샷 시대의 포트폴리오 역설: 만들기가 쉬워질수록 "만들었다"의 증명력은 떨어진다.
  평가 축은 "만들 수 있나"가 아니라 "왜 이렇게 만들었는지 말할 수 있나"로 이동.
- 지연의 희소성 = 이력의 시간축. 같은 문제를 시대가 바뀔 때마다 새 도구로 다시 푸는 사람.
  슬로건의 개인사 버전: "내가 한 번 손으로 풀었던 문제를, 새 도구로 다시 푼다."
- 조건: 낡은 기술 부활은 반드시 현재의 장면과 짝지을 것. 부활의 명분은 항상 지금의 요구.
- 버릴 것: 장면도 역사도 없는 데모. 남길 것: 지연의 시간축 위에 서 있는 것.

## 4. 1주 단위 프로젝트 (P 라인업)

| P | 프로젝트 | 장면 | 격차 | JD 매핑 |
|---|---|---|---|---|
| P1 | AI 페르소나 채팅 | 팬이 가상 아티스트와 실시간 대화, 토큰 스트리밍 | LLM streaming, WebSocket | 실시간 채팅 |
| P2 | AI 음성 통화 | AI 아티스트에게 전화 걸기 (STT→LLM→TTS 왕복) | TTS/STT 최신 API, 오디오 스트리밍 | AI 음성 통화 |
| P2.5 | AI 영상 스트리밍 통화 | 버튜버 아바타가 서버에서 렌더되어 1:1 영상통화로 흘러나옴 | 서버 아바타 렌더 + WebRTC 송출, 리얼타임 백엔드 아키텍처, 고성능 API | AI 생성 영상 스트리밍 통화 (공고 핵심) |
| P3 | RN 팬 앱 | P1+P2+P2.5를 Expo로 iOS/Android 포팅 | React Native, react-native-webrtc | RN 클라이언트 |
| P6 | 페르소나 장기기억 (RAG) | 아티스트가 팬의 과거 대화·세계관을 기억하고 꺼내 씀 | 임베딩·pgvector 검색·재순위 (RAG 파이프라인) | AI 모델 연동·추론 파이프라인 (LLM/RAG 우대) |
| P4 | 발화 승인 게이트 | AI 아티스트 발화를 사람이 검수/승인, 위험 발화 플래그 | function calling, HITL | 브랜드 세이프티 (agent-0 서사 이식) |
| P5 | 실시간 관제판 | P1~P2.5의 지연·비용·오류율 대시보드 + Sentry | 운영 계측 | 모니터링 우대 |

- 순서: P1 → P2 → P2.5 → P3 → P6 → P4 → P5 (README의 W1~W7과 정렬). 하나의 AI 아티스트
  서비스로 합쳐짐 — "기획부터 구축, 운영, 모니터링까지"를 통째로 시연.
- P2.5(영상 스트리밍 WebRTC)가 공고의 "AI 생성 영상 스트리밍 + 리얼타임 백엔드 + 고성능 API"에
  직결되는 핵심 어필 라인. 서버 렌더 선택 덕에 P3 RN 포팅 시 클라는 스트림 수신만 하면 되어 가벼움.
  이 조정으로 P4 발화 승인 게이트는 P3·P6 뒤로 밀림.
- P2의 진짜 산출물은 비교 문서: **"2020 vs 2026: AI에게 전화 걸기"** — 같은 문제 두 시대
  아키텍처 비교 글. 코드보다 이 글이 특이점을 만든다. 독립출판(기록자) 이력과 연결.
- 로봇 카드(버퍼/주말): ESP32 스택짱 로봇이 P1 페르소나를 말하게 함 — "AI 아티스트가 화면
  밖으로 나온다". Blue Garage 정체성(IP의 물리적 확장)에 직격.

## 6. 시장성 조사 (2026-09-15)

"실시간 음성/영상 AI + 풀스택" 스택을 요구하는 다른 채용의 존재 확인 — JYP 한 곳용 기술이 아님.

- **국내 AI 캐릭터/팬덤 플랫폼**: 스캐터랩 제타(가입 160만, DAU 30만, 주 12시간 몰입), 뤼튼 크랙,
  디어유 버블, 하이브 위버스 — JYP Blue Garage와 같은 카테고리의 경쟁 지형. 엔터 × AI 캐릭터
  시장 자체가 커지는 중.
- **국내 실시간 음성 AI 채용 실물**: 플릭던 "AI 음성 챗봇 개발자" (LLM/RAG + 다국어 STT/TTS 연동 —
  P 라인업과 거의 동일 스택), AI 통역 스타트업들, AICC(콜센터 보이스봇) 섹터가 2026년 텍스트 챗봇에서
  보이스봇으로 이동 중.
- **해외**: voice agent 풀스택이 독립 카테고리로 형성됨 — LiveKit/Pipecat/Deepgram/ElevenLabs 생태계,
  "STT + LLM 오케스트레이션 + TTS + WebRTC 저지연" 요구 공고 다수, 원격/연봉 ~$200k 수준.
  LiveKit과 Pipecat은 사실상 WebRTC의 현대 계승자 — 지연의 2019-2020 WebRTC 경험이 연결되는 지점.

판단: **이 기술을 파는 건 JYP 베팅이 아니라 카테고리 베팅** — 국내(엔터, AICC, 통역)와 해외(voice
agent) 양쪽에 재사용처가 확인됨. 유의점: 국내 공고 밀도는 일반 FE보다 낮은 니치이므로, P 라인업은
"음성 AI 전문가 되기"가 아니라 "풀스택 + 실시간 AI 연동 증거 만들기"로 자리매김할 것 (일반 풀스택
공고에도 통하는 각도 유지).

측정 원칙(one-shot 경계, 개입 5종, 격차+장면)은 `계획.md` 그대로 적용 — 공장은 유지, 테스트 케이스만 교체.
