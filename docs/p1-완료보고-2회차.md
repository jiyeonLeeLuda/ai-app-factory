## 무엇을 만들었나 (주요 파일·화면)

**화면 (App Router)**
- `/` (`app/page.tsx`) — 아티스트 리스트(필립·아바타 플레이스홀더). 쿠키 없으면 `/signup`으로
- `/signup` — 닉네임+이메일 가입 폼 (`SignupForm.tsx`, httpOnly 쿠키 세션 발급). 쿠키 있으면 건너뜀
- `/rooms` — 내 대화방 목록(조회만, 아티스트명·마지막 메시지 미리보기)
- `/chat/[slug]` — 채팅방. 서버는 방을 **조회만**(없으면 "대화를 시작해보세요" 안내), 클라 `ChatRoom.tsx`가 **문장 단위 다중 말풍선 SSE 스트리밍·"…" 타이핑·중지·에러+재시도** 처리

**API (Node 런타임)**
- `POST /api/signup` — User 생성 + httpOnly 쿠키, 이메일 중복 409
- `POST /api/chat` — upsert 방 생성 → user 메시지 저장 → OpenAI Responses 스트림을 **문장 경계로 잘라** SSE `sentence` 이벤트로 릴레이 → **문장당 assistant `Message` 1행** 저장

**lib/** — `prisma`(싱글턴), `openai`(모델·상한·추론 effort env), `session`(현재 사용자 판별 격리 S2c.4), `sentence`(문장 경계 스테이트풀 분할기 S1b), `validation`(zod)
**prisma/** — S2 스키마 그대로 + 필립 시드(`slug=philip`)

## 이번 라운드의 핵심 구현 (S1 진화 B안)

- 서버가 토큰 스트림을 **문장부호(`. ! ? 。 ~ …`) 또는 줄바꿈**으로 잘라 `sentence` 이벤트로 emit
- 클라는 문장을 큐에 받아 **~600ms 시차**로 하나씩 말풍선 노출, 전송 직후부터 **"…" 점멸 타이핑** 표시
- **다중 턴 안전**: 매 전송마다 큐·타이머·done 플래그 완전 초기화(`turnRef`로 이전 턴 잔여 타이머 무효화) — 2턴째 blank 버그 방지
- **중단**: 남은 큐 flush + 마지막 문장에 `…(사용자가 중단함)` 부착 저장
- **실패**: 부분 텍스트 미저장 + 실패 턴 말풍선 제거 + 재시도(기존 user 메시지 재사용)

## 내가 스스로 정한 가정

1. **`reasoning: { effort: "minimal" }` 추가** — gpt-5-nano는 추론모델이라 `max_output_tokens:1000`을 추론이 다 먹어 **텍스트가 비는 현상 실측**. minimal로 눌러 예산을 답변에 씀(스펙의 1000 유지, 최저비용 취지 부합). env `OPENAI_REASONING_EFFORT`로 조정 가능. **← 스펙에 없던 파라미터. 원샷 측정 결과로 스펙에 피드백할 지점.**
2. **`.env` 생성 시 값 앞뒤 따옴표 제거** — `.env.shared`가 `KEY="..."` 형태라 그대로 복사하면 dotenv 구현에 따라 401 위험(이식성).
3. 스트림이 정상 완료됐는데 문장 0개면 `done` 대신 `error` 전환(빈 말풍선 조용한 실패 가드).
4. 읽기(리스트/방/히스토리)는 별도 GET 라우트 대신 **Server Component 직접 조회**(Out of Scope 절제).
5. 채팅방 라우팅을 `slug`로 키잉(1회차는 `artistId`). 방=`(user,artist)` 유일이라 동치.
6. 이메일 중복 가입은 409로 거절(W1은 이메일 인증 안 함 → 계정 탈취 구멍 방지, S2c.2).
7. 폴더 리셋 시 삭제 대신 **scratchpad 백업 후 이동**(측정은 깨끗하게, 사고는 되돌릴 수 있게).

## 남은 리스크·미확인

- 모델 id `gpt-5-nano` / `max_output_tokens` / `reasoning.effort` / SSE 이벤트명 — **실 API로 검증 완료(리스크 해소)**.
- **중지 시 서버 저장**은 client abort 후 서버가 flush+저장하는 경로 — Next Node 런타임이 disconnect 후에도 핸들러를 마저 도는 동작에 의존. curl 자동화로는 재현 난망이라 코드만 검증(육안 QA 대상: 중지 클릭 후 새로고침 시 저장 확인).
- `npm audit` high 3건(스캐폴드 기본 의존성) — 기능 무관.
- `git commit`/push는 하지 않았습니다(사람 몫).
