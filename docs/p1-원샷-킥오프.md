# P1 원샷 킥오프 지시문

> 사용법: **새 Claude Code 세션**을 저장소 루트에서 열고 "이 지시문을 읽고 앱을 만들어줘"라고 한 뒤 이 파일을 투입한다.
> (이 세션은 설계 맥락이 없어야 한다 — one-shot 측정의 전제.)

## 지시

`docs/p1-spec.md`를 읽고, **그 스펙이 정의하는 앱을 `apps/w01-persona-chat/`에 end-to-end로 완성**하라.
스펙이 유일한 권위다. 이 지시문에 없어도 스펙에 있으면 따르고, 스펙에 없으면 만들지 마라.

## 입력

- **스펙(권위)**: `docs/p1-spec.md` — 장면·격차·UX·데이터 모델·엣지·비기능·검증·Acceptance·**S6 부트스트랩 규칙**이 다 들어 있다.
- **공유 시크릿**: `factory/.env.shared` — `OPENAI_API_KEY`, `CREATE_DB_URL`. 여기서 읽어 앱 `.env`를 생성한다(스펙 S6).

## 실행 순서 (스펙 S6 그대로)

1. **폴더 리셋** — 대상은 `apps/w01-persona-chat/`. 있으면 삭제 후 재생성.
   - ⚠️ 삭제 전 **삭제할 절대경로를 반드시 출력(echo)** 하고, 그 경로가 정확히 `.../apps/w01-persona-chat/` 인지 확인하라. **상위 디렉터리·다른 앱 폴더는 절대 건드리지 마라.**
2. Next.js(App Router)+TS 스캐폴드 (이 폴더 안).
3. `factory/.env.shared`로 앱 `.env` 생성 — `OPENAI_API_KEY` 복사, DB 이름 = 슬러그(`w01_persona_chat`), `CREATE_DB_URL`의 `/postgres`→`/w01_persona_chat` 치환해 `DATABASE_URL` 기록. `.env.example`도 생성.
4. `prisma migrate dev`(DB 생성+테이블) → `prisma db seed`(필립).
5. 스펙 S1~S4 구현 → S5 검증.

## 자율성 (중요)

- **완료까지 사람에게 묻지 말고 자율로 진행**하라. 애매한 지점은 스펙 우선, 스펙에 없으면 합리적 기본값으로 정하고 **무엇을 가정했는지 기록**하라. (중간 질문은 측정을 흐린다)
- 완료를 선언하기 전 **스펙 S5 검증 명령을 스스로 실행**하고, **Acceptance Criteria를 자가 점검**하라.

## 완료 시 보고

- 무엇을 만들었는지 (주요 파일·화면 요약)
- S5 검증 결과 (typecheck/lint/build/prisma validate/migrate/seed 각각 통과 여부)
- Acceptance 자가 점검 결과 (통과/미달 항목)
- 내가 스스로 정한 가정 목록
- 남은 리스크·미확인 (예: 모델 id 유효성, `max_output_tokens` 실제 파라미터명)
