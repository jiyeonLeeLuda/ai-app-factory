## 1. 앱 정의 (씨앗 기준 — Step 0에서 재확정)

- **W3 = AI 아바타 영상통화.** 팬이 AI 아티스트(**luda**)와 영상통화 → AI가 대화 내용을 **TTS로 말하며, 오디오에 맞춰 입을 움직이고 emotion에 따라 표정**을 짓는 3D 캐릭터.
- **씨앗 확정**: 3D 전부 클라 렌더, 서버 = **API 키 프록시만**(미디어서버·서버렌더 없음). STT → LLM(JSON `{text, emotion}`) → TTS 오디오 → 클라에서 **오디오 진폭→입(aa)** + **emotion→표정**.
- **W2.5와 결정적 차이**: **사람 얼굴 트래킹 없음.** 구동 소스 = 웹캠(W2.5) → **AI 오디오·emotion**(W3).

## 2. W2.5 자산 이어받기 (핵심 — 이게 W3를 지금 하는 이유)

- **VRM 렌더 파이프라인** = `apps/w025-face-track-call/lib/render/characterRenderer.ts`(숫자→`expressionManager`+head/arm bone) **그대로 재사용.** 구동 소스만 웹캠→AI 오디오/emotion으로 교체. (씨앗의 "숫자→클라 렌더" 수신부 = B안 자산)
- **페르소나 DB**(luda `Artist`), **custom https server**, **내부망 HTTPS**(mkcert `factory/certs/172.10.102.176+3.pem`), **Secure 쿠키**.
- **실측 함정4 예방**(함정 회고): 내부망 실기기 = `allowedDevOrigins`+Secure 쿠키+Safari(iOS Chrome은 로컬 CA 거부)+rootCA 3단계 신뢰. **실기기 실측은 production 빌드 권장**(dev HMR·origin 제한 회피).

## 3. 절차 (감산형 pre-spec 게이트 — 순서대로)

**Step 0** — 목적 한 줄 + 축 tilt(X 기술어필/Y 팩토리/Z 빈지식, 기본 Y>X>Z) + 축별 승리조건.
**격차 하나로 감산** — 아래 조각을 3축 채점(vibes 금지)해 격차 1개로. 나머지 Out of Scope/스트레치.
- 조각 후보: **STT 경로**(웹 Web Speech API vs 서버 OpenAI `/audio/transcriptions`) / **LLM emotion 구조화출력**(JSON `{text,emotion}`) / **TTS→오디오진폭 립싱크**(Web Audio `AnalyserNode`→`aa`) / **emotion→표정 전환**(lerp) / **프록시 위치**(W2 custom server 연장 vs Cloudflare Workers/Vercel) / **지연 최소화**(LLM 스트리밍+문장 단위 TTS — W2 자산).
**선행조사**(공식문서·서브에이전트, 기억 금지) — STT/TTS API 규격·모델명·비용, 오디오진폭 립싱크 구현, LLM 구조화출력(JSON) 규격.
**grilling** — pre-spec 초안 → `/grill-me` 압박 검증.
**SPEC 작성** — `factory/SPEC_TEMPLATE.md`로. 사람 준비물·검증·Acceptance 명시.
