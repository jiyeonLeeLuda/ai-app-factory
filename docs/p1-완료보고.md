# 완료 보고 — P1 페르소나 채팅

## 무엇을 만들었나 (주요 파일·화면)

**화면 (App Router)**
- `/` → 쿠키 유무로 `/signup`·`/artists` 분기
- `/signup` — 닉네임+이메일 가입 폼 (`SignupForm.tsx`, 쿠키 세션 발급)
- `/artists` — 아티스트 리스트(프로필·아바타 플레이스홀더)
- `/conversations` — 내 대화방 목록(조회만, 마지막 메시지 미리보기)
- `/chat/[artistId]` — 채팅방. 서버는 방을 **조회만**(없으면 "대화를 시작해보세요" 안내), 클라 `ChatRoom.tsx`가 **토큰 단위 SSE 스트리밍·중지·에러+재시도** 처리

**API (Node 런타임)**
- `POST /api/signup` — User 생성 + httpOnly 쿠키
- `POST /api/chat` — upsert 방 생성 → user 메시지 저장 → OpenAI Responses 스트림을 SSE로 릴레이 → 완료 시 assistant 저장

**lib/** — `prisma`(싱글턴), `openai`(모델·상한 env), `user`(현재 사용자 판별 격리, S2c.4), `conversation`(P2002 경쟁 방어 upsert), `validation`(zod)
**prisma/** — S2 스키마 그대로 + 필립 시드

## 내가 스스로 정한 가정

1. **`factory` Postgres role이 없어 직접 생성** — 슈퍼유저 `mediquitous`로 `CREATE ROLE factory ... CREATEDB PASSWORD 'aj8611'` (스펙 DATABASE_URL 변경 없이 사람 준비물 ② 공백을 메움). *경계 밖 파일은 손대지 않음 — DB role 생성만.*
2. **Prisma 6로 다운그레이드** — `npm i prisma`가 8.0 RC를 잡았고 v7+는 `url=env()` 폐기·driver adapter 강제라 스펙의 클래식 `migrate/seed` 흐름과 충돌. v6가 스펙이 가정한 워크플로우와 일치.
3. 라우팅: 채팅방을 `artistId`로 키잉(방=`(user,artist)` 유일이라 동치). 대화방 목록도 `artistId`로 진입.
4. 재시도 판별: 클라가 `retry:true` 전송 → 서버는 user 메시지 재생성 안 함(S3 중복 방지).
5. 1:1 UI라 내 말풍선에 닉네임 라벨 미표시(`Message`에 유저 정보 비복제 원칙은 유지).
